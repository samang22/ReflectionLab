# 3·4·7라운드 전투 구도 수정

## 적용 위치

- 3라운드: `DA_CrossfireExperiment` → `Crossfire`
- 4라운드: `DA_AccelerationField` → `Field Layout`, `Acceleration`
- 7라운드: `DA_MirrorArena` → `Mirror`

`DA_DefaultRun.Rounds`의 기존 연결은 변경하지 않았다. 기존 진행·보상·체력·패턴 빈도도 유지한다.
`Scripts/Editor/SetupArenaCombatRevision.py`를 직접 실행해 세 에셋만 백업·저장·재로드 비교했다.
추가 실행은 이후 수동 튜닝을 덮어쓸 수 있으므로 필요할 때만 사용한다.

## 3라운드: 가변 미로

`Maze Walls` 배열의 8개 패널이 두 Phase Group으로 번갈아 상승·하강한다.
패널별 중심·크기·회전·그룹을 에디터에서 편집한다. 빈 배열이면 기존 두 벽 구성을 사용한다.
가운데 넓은 통로와 외곽 순환로를 남겼으며 적은 양쪽 외곽에 배치한다.
기존 경고·이동 시간은 유지하고, 플레이어가 패널 위에 있으면 상승을 보류한다.
회전된 패널도 로컬 방향으로 점유를 계산하며 높이는 점유 판정에서 제외한다.

## 4라운드: 가속 반사탄 필터

`Enable Return Barriers`를 켜고 좌우 x=-950/+950에 필터를 배치했다.
`Return Barrier Centers`, `Return Barrier Size`로 배치·충돌 크기를 조정한다.
플레이어는 필터 안에서 싸우고 적은 필터 밖에 생성된다. 적 이동은 이 기믹 동안 제한한다.
필터는 플레이어의 이동을 막지만, 시각 메시는 낮춰 캐릭터를 가리지 않는다.

- 적 탄환: 안쪽으로 들어올 수 있도록 통과 허용
- 일반 반사탄: 필터에서 흡수·풀 반환
- 패리 후 가속 구역을 지난 반사탄: 통과 허용, 필터가 청록색으로 짧게 점멸
- 자격 없는 반사탄: 주황색으로 차단 피드백

단순 속도나 속도 증강 수치로 통과하지 않는다. 투사체의 현재 비행에
`AccelerationCharge` 상태를 부여하고 풀 획득·패리 시 초기화한다.
고속탄이 한 프레임에 가속 구역과 필터를 모두 지나도 필터 접촉 지점까지의 경로를 먼저 검사한다.
필터 뒤쪽의 가속 구역을 선행 통과로 잘못 인정하지 않는 검사도 포함했다.
같은 라운드의 다음 웨이브에서는 필터를 재생성하거나 플레이어를 다시 중앙으로 이동시키지 않는다.

### 가속 영역 소형화·분산 배치 (2026-10-27)

- 2개 긴 영역 → 6개 작은 영역 (좌우 각각 위·중앙·아래)
- 각 영역의 전체 크기: 360×2200 → 240×440cm
- 중심: x=-600/+600, y=-900/0/+900
- 가속 배율·장벽 크기·위치·패턴 빈도는 변경하지 않음
- `TuneAccelerationFieldLayout.py`에서 공통 preview/apply 절차로 저장·재로드 확인
- 가속 장벽 테스트에 모든 배치 영역의 실제 swept 반사탄 통과 검사를 추가

## 7라운드: 직접 사격 차단 확대

- `Shot Barrier Length`: 270 → 480
- `Diagonal Mirror Center`: (950,800) → (950,1100)
- `Mirror Camera Arm Length`: 4300 → 4600

이동 제한 구역과 벽 시각 높이는 유지했다. 긴 차단벽 때문에 반사 경로까지 막히지 않도록
반사판을 조금 더 바깥으로 배치하고 카메라 범위를 함께 조절했다.
중앙 전투 구역의 직접 경로를 줄이는 구성이지 모든 가능한 위치의 직사를 수학적으로 봉쇄하는 것은 아니다.

## 검증

- Development Editor 빌드 성공
- 설정 적용 commandlet: 3개 에셋 저장·재로드 결과 일치
- 전체 ReflectionLab 자동 테스트 31개 성공
- 로그: `Saved/Logs/ArenaCombatRevisionFinal.log`
- 백업: `Saved/Migrations/ArenaCombatRevision_20261026_223304_039353`

추가된 실제 저장 에셋 기반 테스트:

- `AccelerationBarrier`: 일반/가속 반사탄, 속도만 빠른 탄환, 고속 sweep, 풀 상태 초기화, 필터 외부 적 배치·플레이어 이동 차단, 웨이브 재설정·정리
- `CrossfireMaze`: 두 위상 각각 4개 벽 상승, 260cm 폭의 이동 여유를 반영한 4방향 도달 검사, 실제 탄환 차단·통과, 플레이어 점유 시 상승 보류
- `ExpandedMirrorRoutes`: 8개 적 위치의 실제 swept 탄환 왕복, 실제 반사 횟수, 중앙의 대표 위치 3곳에서 직접 경로 차단

이 검사는 임시 물리 월드에서 수행했다. 실제 맵의 화면 연출·재미·난이도·패키징은 별도 플레이 검증이 필요하다.
바로 확인하려면 `DA_DefaultRun.StartingRoundNumber`를 3, 4, 7로 변경하고 각각 PIE를 실행한다.
배포 전에는 0으로 복원한다. 이번 작업에서는 이 값을 변경하지 않았다.
