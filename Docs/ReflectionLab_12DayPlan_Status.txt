[D] 주의사항
============

- Projectile Definition DA가 탄 고유 스펙의 기준이다.
- Difficulty DA는 출현 빈도와 발사 패턴의 기준이다.
- Projectile Rules는 배열 위에서부터 검사하며 첫 번째 일치 규칙이 적용된다.
- 테스트 에셋과 실제 라운드 에셋을 구분해 실험 결과를 먼저 확인한다.
- 에디터에서 실제 플레이 테스트를 완료하기 전에는 기믹이 최종 확정된 것으로 간주하지 않는다.


[E] 적용된 라운드 레벨디자인
=============================

Tutorial - 3개 웨이브 핵심 조작 학습 (정식 라운드 집계 제외)
- BasicParry: 일반탄으로 이동과 기본 패리 확인
- ReadTheShot: 폭발탄과 불가드탄 구분
- ComboTrial: 랠리탄 처리와 연속 패리 연습

Round 1 - 기본기를 안다는 전제의 즉시 압박
- HotEntry: 폭발탄과 불가드탄이 섞인 상태에서 시작
- RallyPressure: 랠리탄과 불가드탄 동시 처리
- MixedPressure: 폭발, 불가드, 랠리 조합
- BurstLine: 2연발과 높은 적 밀도로 압박
- Breather: 특수탄 없이 호흡 회복
- Overdrive: 짧은 생성 간격과 2연발 유지
- FinalSurge: 동시 생성과 최고 적 밀도로 기본기 최종 시험

Round 2 - 관찰, 타이밍, 목표 선택
- R2_Warmup: 불가드와 랠리로 Round 1 복습
- R2_RelayLine: 양방향 교차탄과 랠리 조합
- R2_BombEscort: 지연 폭발탄과 보호막 적 도입
- R2_Crossfire: 교차탄 중심 방향 판단
- R2_Breather: 특수탄 없이 호흡 회복
- R2_Deception: 페이크탄, 지연 폭발탄, 교차탄, 보호막 조합
- R2_RelayStorm: 페이크 폭발 보상과 랠리/교차 압박의 종합 시험

Round 3 - 복합 패턴과 숙련도 시험
- R3_HotStart: 위험 분열탄, 교차탄, 랠리, 보호막으로 즉시 시작
- R3_FuseField: 지연 폭발, 일반 폭발, 페이크 판단 시험
- R3_RallyBombs: 폭발탄과 랠리탄 사이의 목표 선택
- R3_FractureCrossfire: 위험 분열탄과 2연발 교차탄 조합
- R3_Breather: 최종 구간 전 호흡 회복
- R3_RedZone: 페이크, 지연 폭발, 위험 분열, 교차탄 복합 구간
- R3_FinalOverload: 모든 기믹과 보호막 적이 등장하는 최종 시험

공통 설계 원칙
- 각 라운드 중간에 적 수가 적은 Breather 웨이브를 유지한다.
- 고난도 탄에는 분열, 관통, 범위 폭발, 콤보 상승 등 큰 보상을 연결한다.
- Projectile Rules는 배열 위쪽 규칙이 우선 적용된다.
- Round 3 최종 구간도 가독성을 위해 동시 적 수를 7명으로 제한한다.


[F] 12일 계획 이후 Steam 등록 계획
===================================

12일 계획은 플레이 가능한 프로토타입 완성을 목표로 한다. Steam 등록과 출시 준비는
프로토타입 검증 이후 별도 단계로 진행한다.

Steam 등록 1단계 - 계정과 앱 설정
- Steamworks 파트너 계정 및 세금/지급 정보 등록
- Steam Direct 앱 등록비 결제
- ReflectionLab 앱 ID 생성
- 개발자 연락처와 법적 고지 정보 입력

Steam 등록 2단계 - 스토어 페이지 준비
- 게임명, 짧은 설명, 상세 설명 작성
- 장르, 태그, 지원 언어, 시스템 요구사항 입력
- 캡슐 이미지, 헤더 이미지, 라이브러리 이미지 제작
- 게임플레이 스크린샷과 짧은 트레일러 준비
- 패리, 랠리, 특수탄 등 핵심 차별점 중심으로 설명

Steam 등록 3단계 - 빌드 업로드
- Shipping 빌드 생성
- Windows 실행 파일과 필수 런타임 확인
- SteamPipe depot/app 구성
- 비공개 테스트 브랜치에 빌드 업로드
- Steam 클라이언트에서 설치, 실행, 삭제, 업데이트 확인

Steam 등록 4단계 - QA와 검수 준비
- 첫 실행, 저장, 재시작, 실패, 완주 흐름 테스트
- 키보드/마우스 입력과 해상도별 UI 점검
- 패키지에 개발용 로그, 테스트 에셋, 임시 파일이 포함되지 않았는지 확인
- 크래시와 치명적 로드 오류 확인
- 상점 페이지와 실제 빌드의 설명/스크린샷 일치 여부 확인

Steam 등록 5단계 - 출시 전 운영
- Steam Playtest 또는 비공개 베타 운영
- 플레이어 피드백 수집 및 치명적 버그 수정
- 출시 버전 태그와 백업 생성
- 출시일, 가격, 얼리 액세스 여부 결정
- 업데이트와 핫픽스 배포 절차 준비
